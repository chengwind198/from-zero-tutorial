# 单篇模式流程（Single Article Mode）

> 由 SKILL.md「模式路由」命中单篇模式后使用。**只按本文件执行**，禁止执行系列专属节点：
> 不建系列规划.md、不建素材库.md、frontmatter 不写 lesson、正文不写「下一步」、收尾不回填三处。

## 适用场景

用户只给一个标题或主题，要求写一篇文章（公众号文章、独立文章）；或路由无法判断默认落入单篇模式。面向公众号/公开传播的文章，同时套用 [viral-writing.md](viral-writing.md) 的爆款写作规范。

## 输出目录

所有产出一次性放入 `<项目根>/generated/<英文标题>/`（见 SKILL.md「输出目录约定」）。英文 slug 由你根据主题自拟：全小写、字母数字与连字符组成（如 `claude-code-vs-codex`），在「大纲与标题候选」中一并报给用户（即写即报，不等确认）。

下文命令示例默认在技能根目录（SKILL.md 所在文件夹）执行，`--input` / `--root` 指向 `<项目根>/generated/<英文标题>/`，路径写绝对路径或从技能根目录到目标的相对路径均可。

## 流程（要素确认 → 取材 → 大纲即写即报 → 一次性产出）

### 1. 要素对齐（主题 / 目标读者 / 核心观点）

用户未提供主题、目标读者、核心观点中的任一项时，先主动提问补齐（可给出默认建议让用户选）；三要素齐备即可进入取材（默认自动推进，无需再等「直接写」指令）。

### 2. 取材（铁律）

web search 只针对本文主题；关键数据双源核实（至少两个独立来源），来源与核验日期记入「本文素材清单」。对时效敏感主题（模型/版本/价格/政策/产品/榜单等），先锚定「截至写作日的最新事实」：优先最近发布来源与官方发布页，新旧口径冲突以最新官方为准，正文标注数据日期（如「截至 2026-09-04」），过时数据只作明确标注的历史对比。检索执行标准：快节奏主题（如 AI 模型/价格/榜单）默认采用最近 90 天内发布的口径，超过 1 年的结果只作历史背景；搜索结果优先看 publish_date 近的来源，第一轮检索后发现锚点疑似过期，追加一轮定向时效搜索再动笔。素材较多或需要留档时，落盘 `<项目根>/generated/<英文标题>/素材.md`（单篇轻量取材记录，命名避开系列的「素材库.md」）。禁止编造案例、数据、对话；材料不齐不写。

### 3. 大纲与标题候选（即写即报，不等待确认）

动笔前在对话中给出：

- 简短大纲：3-5 个正文小节 + 配图规划 + 建议目录 slug；
- **3 个标题候选**：按爆款三策略（悬念 / 数字 / 情绪）或组合给出（用户已给定标题时，给 3 个副标题候选），并标出推荐项；
- 给出后**直接进入下一步写作**，不等待确认；用户若在对话中对标题/立场/读者提出调整，按其意见修改后继续。

### 4. 写作（一次跑完）

大纲与标题候选同步给出后，从写作到校验、收尾一次跑完，全部输出文件**一次性生成**到 `generated/<英文标题>/`：文章 .md、（若建）素材.md、assets/、（可选）html/。

- 正文字数 3500-8000（check-articles.mjs 默认区间，与系列一致）；
- 规范同 [article.md](article.md)：场景开场、术语首现一句话解释、至少 1 个真实案例、至少 1 组数据表、误区澄清、延伸阅读、一稿二改去 AI 味；
- 面向公众号发布时按 [viral-writing.md](viral-writing.md) 补传播基因：前 100 字钩子、每 300 字停靠点、每 500 字金句、结尾行动号召 + 互动话题；
- 标题：从候选里选推荐项（用户给定标题时保留用户标题，副标题负责钩子）；用户中途指定则按用户指定；
- frontmatter：用 [assets/templates/article-single-template.md](../assets/templates/article-single-template.md)（无 lesson）；
- 章节结构：正文 →（操作类加「本节难点 / 要点速记 / 动手任务 / 完成标志 / Q&A」）→ 参考/延伸阅读 →（公众号发布必设）行动号召与互动话题；不设「下一步」，也不在正文里写「配图登记」（图片锚点登记写进素材.md 或对话/交付说明）。

### 5. 配图（强制）

- 封面：`node scripts/cover-generator/generate.mjs --input "<项目根>/generated/<英文标题>/<文章>.md" --width 1068 --height 455 --out "<项目根>/generated/<英文标题>/assets/<封面>.png"`（公众号 2.35:1；title 自动取 frontmatter title）；把随机到的 style slug 回填 frontmatter `style`；
- 正文图：正文每个一级小节（## 标题）至少 1 张（同一张图不跨小节复用），来源可混用——模板卡统一与封面同一 style，实拍截图 / Mermaid / AI 生图按内容补充混用（完整规则见 images.md）；「本节难点 / 要点速记 / 动手任务 / 完成标志 / 常见问题 Q&A / 参考 / 延伸阅读 / 行动号召 / 配图登记」等辅助或收尾小节不计入；
- 目录：封面与正文图都放文章目录 `assets/` 下即可（不强制 assets/NN/）。

### 6. 验证与收尾

1. `node scripts/check-images.mjs --root "<项目根>/generated/<英文标题>" --strict` —— 必须 0 断链、0 未用图、0 缺封面、0 缺正文图、0 缺小节图；
2. `node scripts/check-articles.mjs --root "<项目根>/generated/<英文标题>" --strict` —— 字数 3500-8000；
3. `python scripts/md-to-html.py --input "<项目根>/generated/<英文标题>/<文章>.md"` —— 微信兼容 HTML，无 `{{...}}` 残留；
4. `python scripts/publish-wechat.py --input "<项目根>/generated/<英文标题>/<文章>.md" --dry-run` —— 核对账号/标题/图片清单；正式发布必须先得到用户确认；
5. 图片锚点回填：文章位于已有系列目录内 → 并入该系列素材库.md 对应条目（封面/正文图文件名 + 锚点说明，写法同系列 17-20 课）；完全独立的单篇 → 图片锚点登记写进素材.md 或对话/交付说明，不写入文章正文；
6. 收尾产物只应有：文章 .md、（若建）素材.md、assets/ 图片、（可选）html/、（若发布）发布记录。

## 与系列模式差异速查

| 差异点 | 系列模式 | 单篇模式 |
| --- | --- | --- |
| frontmatter lesson | 必填 | 无 |
| 「下一步」章节 | 必设 | 不设（以延伸阅读/行动号召收尾） |
| 系列规划.md / 素材库.md | 必建 | 不建（可用轻量素材.md 留档取材） |
| 回填 | 进度表 + 合集 + 素材库三处必做 | 仅图片锚点登记（系列目录内必做，独立单篇写入素材.md 或交付说明） |
| 配图校验 | check-images.mjs（默认） | check-images.mjs --strict |
| 字数校验 | check-articles.mjs（默认，仅带 lesson） | check-articles.mjs --strict |
| 前置确认 | 要素缺失时提问补齐；规划要点即写即报，不主动停笔 | 要素缺失时提问补齐；大纲 + 3 个标题候选即写即报，不等待确认直接成文 |
| 升级为系列 | — | 补建规划.md + 素材库.md + lesson + 「下一步」后继续 |
