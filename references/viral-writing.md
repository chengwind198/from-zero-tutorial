# 爆款流量密码（传播写作规范）

面向公众号/公开传播的文章（单篇观点文、独立文章、系列篇目）在成稿前阅读本文。本文与 [article.md](article.md)、[single-mode.md](single-mode.md) 配套：只管「传播基因」，不替代取材、核实、配图、一稿二改等硬规则。

## 适用边界与冲突消解

1. 本文是**表现层规范**：标题可以有钩子、正文可以有情绪，但不得覆盖技能铁律——取材先行、双源核实、禁止编造案例/数据/对话、配图强制、写完必验、一稿二改；
2. **标题党红线**：悬念/数字/情绪必须与正文强相关，正文兑现标题承诺；数字必须真实可核实（「80% 的人不知道」这类表述要有依据，否则删掉或改写为可核实口径）；
3. **节奏与结构冲突**：公众号观点/短文优先用真实小标题，尽量贴近「每 300 字一节」；3500-8000 字长教程按知识点组织小节（避免把长文切碎、避免配图数量失控），节内用加粗核心句、分点列表、配图承担「每 300 字左右一个滑动停靠点」的密度要求；配图强制维持「每个 ## 小节至少一张图」不变；
4. **真实感边界**：可写自己的亲历故事，但不得虚构「我朋友/我学员」式故事；引用他人的案例、访谈须有来源；无法核实的内容不写，或标注「以官方为准」并附链接。

## 1. 标题策略（悬念 / 数字 / 情绪三选一或组合）

| 策略 | 示例方向 | 要点 | 禁忌 |
| --- | --- | --- | --- |
| 悬念型 | 「为什么我劝你别急着 XX」「这件事背后藏着一个真相」 | 留一个正文会兑现的悬念，让人想点开 | 故弄玄虚、正文不揭晓、标题与内容脱节 |
| 数字型 | 「3 个方法」「5 个迹象」「80% 的人不知道」 | 数字具体、稀缺，正文逐条兑现 | 数字无依据、夸大、凑数 |
| 情绪型 | 「我终于放下了 XX」「那一刻我决定……」 | 情绪与文章底色一致，有代入感 | 廉价情绪绑架、卖惨、与观点无关 |
| 组合 | 「3 个迹象说明你在无效努力，第 2 个我中了 5 年」 | 数字 + 悬念 / 情绪叠加，主标题信息更密 | 超过可读长度、承诺过载 |

硬性约定：

- 主标题尽量 ≤ 24 字，包含主题关键词（利于搜索收录）；系列篇目主标题保持「XXX 零基础入门 · NN：…」，爆款钩子落在**副标题**；
- 单篇/观点文在「大纲与标题候选（即写即报）」阶段同步给出 3 个标题候选（含推荐项），随后直接成文、不等待确认；用户给定标题时保留用户标题，钩子由副标题承担；
- 标题与正文强相关，禁止「标题党」——这是流量红线，也是信任底线。

## 2. 开头（前 100 字定生死）

三种开场任选其一，前 100 字内完成「你是谁 / 有什么痛点 / 为什么要读」：

- **场景化故事**：一个人 + 一个具体时刻 + 一个冲突（「上周有读者问我：学了三个月还是不会，是不是没天赋？」）；
- **反常识数据**：给一个有冲击力、可核实的数字或对比（「同一个知识点，A 方法 10 分钟学会，B 方法要 3 小时——差的不是努力，是顺序」）；
- **灵魂拷问**：用第二人称直接戳痛点（「你是不是也收藏了一堆教程，却从没动手写过一行？」）。

禁忌：寒暄、背景铺陈、「随着 XX 的发展」「在当今时代」式空话、AI 腔总结开场。

## 3. 正文结构（黄金圈 / SCQA 变体）

最小骨架：**痛点共鸣 → 原因剖析 → 解决方案/观点输出 → 升华总结**。

- 黄金圈：先讲 Why（为什么重要/为什么错），再讲 How（怎么做），最后 What（具体是什么/做什么）；
- SCQA：情境（Situation）→ 冲突（Conflict）→ 问题（Question）→ 回答（Answer）；
- 教程类文章按知识点分节时，把上述骨架用在开头引导 + 结尾升华，中间每节独立成「小结构」；
- 每 300 字左右至少一个滑动停靠点：小标题、加粗金句、分点列表或配图；
- 每段不超过 5 行（手机屏 2-3 行为佳），多用短句、断行；核心句加粗，不整段加粗。

## 4. 情绪价值与金句密度

- **每 500 字至少一句「可截图分享」的金句**：朗朗上口、带立场、20-40 字为宜，加粗独立成段（如「你缺的从来不是天赋，是一份不赌天赋的路线图」）；
- 金句要有观点和判断，「努力就有回报」「坚持就是胜利」这类不正确的废话不算；
- 适当使用第二人称「你」，增强对话感与代入感，但不滥用、不指责读者；
- 犀利 ≠ 刻薄：观点鲜明、直接给判断，但不居高临下说教。

## 5. 数据 / 案例强化

- 每篇至少 **1 个真实案例或亲历故事** + 适量**具体数字/对比**（含对比表）；
- 关键数据双源核实，来源链接与核验日期记入素材库（单篇记入 `素材.md` 或对话/参考节）；
- 时效敏感数字（模型/版本/价格/规模等）是「写作日快照」：正文与图里注明「截至 YYYY-MM-DD」，优先最新官方口径，避免发布后迅速过期；历史对比数字明确标年代；
- 案例必须是真人真事或可核实事件；禁止编造、移花接木、夸大；
- 数字型标题里的每个数字，正文都要给出依据。

## 6. 结尾：行动号召（CTA）与互动话题

面向公众号发布的文章，结尾必须有：

- **行动号召**：点赞/在看/留言/转发可按平台组合引导（避免「转发到 N 个群」类诱导话术）；
- **互动话题**：一个具体、低门槛、能引发讨论的问题（如「你中过第几条？评论区聊聊」「你会先试哪个方法？」，优于「欢迎留言」）；
- 系列文章的「下一步」预告与 CTA 并存：全系列固定 CTA 位置（一般放最后作为整篇收尾），不每篇换位置。

## 7. 语气（Tone）

亲切、犀利、真诚；避免说教；口语化但逻辑严密。

- 像跟人说话，不用抽象大词和术语堆砌；术语首次出现给一句话解释；
- 观点要有立场、有理由，不骑墙；不制造焦虑，不贩卖情绪；
- 真诚指不装、不端着、承认局限（「这部分以官方文档为准」），而非煽情。

## 8. 成稿检查清单

- [ ] 标题含钩子（悬念/数字/情绪至少一类或组合）且正文兑现，无标题党
- [ ] 前 100 字是场景故事 / 反常识数据 / 灵魂拷问，直接命中痛点或利益
- [ ] 正文覆盖「痛点 → 原因 → 方案/观点 → 升华」（或 SCQA）
- [ ] 每 300 字左右有滑动停靠点（小标题/加粗金句/列表/配图），每段 ≤ 5 行
- [ ] 每 500 字至少一句加粗金句，带立场、可截图
- [ ] 结尾有行动号召 + 一个具体互动话题
- [ ] 至少 1 个真实案例/亲历故事 + 1 组双源核实的数据/对比
- [ ] 语气亲切犀利真诚、无说教腔、逻辑严密
- [ ] 铁律未破：取材先行、无编造、配图与字数校验通过、一稿二改完成
